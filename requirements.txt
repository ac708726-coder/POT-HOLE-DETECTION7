# Streamlit Community Cloud build.

# torch and torchvision are pinned to the "+cpu" local versions, which only
# exist on the PyTorch CPU index. Without the suffix pip is free to take the
# PyPI wheels, which bundle CUDA and run to several gigabytes -- far past the
# Community Cloud resource limit. The install then dies partway and ultralytics
# never lands, which surfaces in the app as "Ultralytics is not installed".
#
# torchvision is here because ultralytics requires it. It is not imported
# directly by this project, so it is easy to leave out by accident.
#
# For local GPU training, install torch and torchvision from the CUDA index
# first (see README), then run this file with --no-deps for the rest. Verify:
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
